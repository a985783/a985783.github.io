If you only need a one-off explanation of a file, stay in chat. If you want the agent to reuse the same boundaries on that codebase, you need a skill path—and the free step is a fit check, not a generator.

Step 1 — Free local Python preflight (license gate first)

Start with a git checkout you are allowed to read.

Run the free preflight:

repo-distillation-preflight

From the skill directory:

python3 scripts/audit_repo_for_distillation.py --repo /absolute/path/to/repository

Hard boundaries (read them twice):

  1. Local Python — inspects license signals and boundary cues on your machine (Python 3.9+, stdlib only).
  2. Does not clone — point it at a checkout you already have; it will not fetch a remote for you.
  3. Does not generate a skill — fit check only; free preflight never emits a skill.
  4. Not legal advice — signals and boundaries for a fit decision; it does not replace counsel.

How to read the verdict

distillation_verdict Meaning Next action
DISTILL Recognized permissive license signal (e.g. MIT, Apache-2.0, BSD, ISC, including SPDX) Still check provenance, notices, file-level exceptions, and your authorization. Write a decision record.
INTERNAL_ONLY Copyleft, source-available, or non-commercial terms (GPL, LGPL, AGPL, MPL, SSPL, RSALv2, BUSL/BSL, Commons Clause, PolyForm, CC-BY-NC) Do not package derived material as a commercial skill. Keep internal or get qualified legal guidance.
NEEDS_REVIEW Missing/unknown license or incomplete evidence Stop. Locate the authoritative license before continuing.
BLOCKED Path is not a directory Correct --repo.

Detection is fail-closed: restricted terms outrank permissive mentions in the same document. DISTILL is a license signal, not quality approval, provenance clearance, or permission to ship a commercial skill.

If the preflight says the repo is out of bounds, stop. Do not pay to paper over a bad fit.
